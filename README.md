# liebeinlinien

## GitHub Pages plan

1. Add a simple static site entry point (`index.html`) for project information.
2. Add a lightweight stylesheet (`style.css`) and keep all assets in the repository root or a dedicated `docs/` folder.
3. Configure GitHub Pages in repository settings to deploy from the selected branch/folder.
4. Verify deployment by opening the published GitHub Pages URL and checking rendered content on desktop and mobile.
5. Document the update workflow so future content changes are made through pull requests.
